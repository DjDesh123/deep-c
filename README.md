# Deep C

A learning repository focused on developing a deeper understanding of C programming, from fundamental syntax to pointers, memory management and debugging.

## Topics Covered

### 1. C Programming Fundamentals
- Variables and data types
- Operators and expressions
- Conditional statements (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Functions, parameters and return values
- Arrays and multidimensional arrays
- String manipulation and standard string functions

### 2. Data Structures and Pointers
- Structures (`struct`) and enumerations (`enum`)
- Pointers and memory addresses
- Pointer dereferencing
- Pointers and arrays
- Passing pointers to functions
- Relationships between arrays and pointers

### 3. Memory Management
- Dynamic memory allocation (`malloc`, `calloc`, `realloc`)
- Releasing allocated memory with `free`
- Stack and heap memory
- Memory ownership and lifetime
- Memory management practices

### 4. File Handling and Error Management
- File input and output
- Reading from and writing to files
- Error handling with `errno` and `perror`
- Assertions using `assert`
- Error checking and failure handling

### 5. Low-Level Programming Concepts
- Bitwise operators
- Bit manipulation
- Working with binary representations
- Memory efficiency and resource awareness

### 6. Debugging and Code Quality
- Debugging with GDB and CLion
- Identifying and fixing programming errors
- Code readability and maintainability
- Refactoring and modular program design
- Unit testing and verification

### 7. Programming Practice
- Problem-solving with arrays, pointers, loops and structures
- Applying C fundamentals to practical programming problems
- Reinforcing concepts through coding exercises

## Development Environment

- **Language:** C
- **IDE:** CLion
- **Debugging:** GDB / CLion debugger
- **Version control:** Git and GitHub
